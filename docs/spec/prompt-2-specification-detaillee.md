# AMIORA — Prompt source n° 2

> Document source fourni par le porteur du projet (Sébastien), reproduit tel quel.
> Slogan : « Prends soin des personnes qui comptent. »

## 1. Vision

Mission : empêcher les relations importantes de s'éteindre par manque de temps, d'attention ou d'organisation.

AMIORA devient : la mémoire de tes relations ; l'agenda de tes proches ; ton album de souvenirs ; ton compagnon relationnel.

## 2. Problème

Les gens : oublient d'appeler leurs parents ; perdent des amis ; négligent leur couple ; oublient des promesses ; ne prennent plus de photos ; regrettent après une séparation ou un décès.

Le problème n'est pas l'amour. Le problème est le manque d'attention au quotidien.

## 3. Cible

**Couple (25-45 ans)** — besoins : plus de temps ensemble ; se souvenir des dates ; organiser des activités.

**Famille** — besoins : appeler davantage ; voir les parents ; préserver les souvenirs.

**Amis** — besoins : maintenir le lien ; organiser des sorties ; éviter de perdre le contact.

**Entrepreneurs** — besoins : équilibrer travail et relations ; éviter de négliger leurs proches.

## 4. Positionnement

Ce n'est PAS : ❌ WhatsApp, ❌ Instagram, ❌ Contacts, ❌ Calendrier.

C'est : ❤️ Relationship OS, 📖 journal de vie, 🎯 organisateur relationnel, 📸 coffre à souvenirs.

## 5. Design

Style : premium minimaliste.

Couleurs : fond noir profond ; cartes anthracite ; accent or premium ; succès vert doux ; alertes orange ; erreurs rouge discret.

Police : titres épais ; texte simple et moderne.

Animations : très fluides ; effet verre ; transitions lentes ; petites vibrations.

Navigation : 🏠 Accueil, ❤️ Relations, ➕, 📖 Souvenirs, 👤 Profil.

## 6. Onboarding

* Écran 1 : logo. « AMIORA — Prends soin des personnes qui comptent. »
* Écran 2 : « Les plus belles relations se construisent avec de petites attentions. »
* Écran 3 : « Nous t'aiderons à : rester présent ; créer des souvenirs ; ne rien oublier. »
* Écran 4 : créer un compte — Continuer avec Apple / Continuer avec Google / Email.

**Premier lancement** — question : « Qui compte le plus pour toi ? ». Minimum : 3 personnes.

Catégories : ❤️ Partenaire, 👨 Famille, 👫 Amis, 👶 Enfants, ⭐ Mentors.

## 8. Écran relations

Liste : photo, nom, catégorie, score, dernière interaction, temps sans contact.

Exemple : ❤️ Emma 94 % (dernière sortie : 5 jours) ; 👨 Papa 71 % (dernier appel : 19 jours).

Filtres : tous, couple, famille, amis, enfants, professionnel.

Recherche : nom, catégorie, date, score.

## 9. Ajout d'une personne

Photo, prénom, nom, catégorie, téléphone, email, date de naissance, adresse, métier.

Préférences : restaurants, couleurs, fleurs, films, loisirs, musique, parfum, taille vêtements, pointure, allergies.

Cadeaux : liste d'idées, prix, liens, notes.

Dates importantes : première rencontre, premier rendez-vous, mariage, diplôme, naissance, promotion, voyages.

## 10. Fiche relation

Photo, nom, catégorie.

Relation : █████████░ 92 %. Niveau : 43. XP : 4 920.

Actions : 📞 appeler, 💬 écrire, 📅 planifier, 🎁 cadeau, 📸 photo, ❤️ souvenir, 📝 note.

Dernières interactions : message (aujourd'hui), appel (hier), sortie (4 jours), cadeau (3 mois).

## 11. Historique

Toutes les interactions. Tri : messages, appels, sorties, voyages, cadeaux, promesses, photos.

## 12. Journal

Exemples : « Papa m'a raconté son enfance. » ; « Thomas a obtenu son nouveau travail. » ; « Emma adore les restaurants italiens. »

## 13. Souvenirs

Photos, vidéos, messages, notes, audio, documents.

Création automatique — 2026 : 14 sorties, 2 voyages, 92 photos, 48 notes.

Vue chronologique : mars, avril, mai, juin.

## 14. Ligne de vie

2022 première rencontre ; 2023 premier voyage ; 2024 emménagement ; 2025 fiançailles ; 2026 naissance.

L'application construit automatiquement l'histoire de la relation.

## 15. Promesses

À faire, en cours, terminées.

Exemples : aller voir mamie ; faire un voyage ; organiser une randonnée ; appeler papa chaque semaine.

## 16. Calendrier

Aujourd'hui, semaine, mois, année.

Événements : anniversaires, sorties, promesses, vacances, dates importantes.

## 17. Relations en danger

Cela fait : 34 jours sans appel ; 72 jours sans sortie ; 119 jours sans visite.

Actions proposées : 📞 appeler ; 🍽️ organiser un repas ; 🎁 envoyer un cadeau ; 📅 prévoir une activité.

## 18. Statistiques

Cette année : 214 appels, 47 sorties, 9 voyages, 416 photos, 63 souvenirs, 284 heures ensemble.

Progression : temps ensemble, nombre de souvenirs, évolution relationnelle.

## 19. Score relationnel

Sur 100.

Variables : temps sans contact, activités ensemble, promesses tenues, sorties, souvenirs, appels, messages.

Exemples : Emma 95 % ; Papa 78 % ; Thomas 43 %.

## 20. Gamification

Chaque relation possède : niveau, XP, badges.

Badges : Communicateur (100 appels), Aventurier (50 sorties), Voyageur (10 voyages), Fidèle (1 an entretenu), Souvenir Keeper (200 photos).

Cercle global : niveau 18 ; XP 8 240 ; relations 8 ; souvenirs 612.

## 21. Défis

Cette semaine : ⬜ voir un proche ; ⬜ faire une activité ; ⬜ appeler un parent ; ⬜ créer un souvenir ; ⬜ faire une surprise.

Défis mensuels : organiser un voyage ; créer 20 souvenirs ; passer 20 heures avec ses proches.

## 22. Capsule temporelle

Écrire un message. Déblocage : dans 1 an ; 5 ans ; mariage ; anniversaire ; naissance.

Exemple : « Cher papa, merci pour tout. »

## 23. Album annuel

Livre automatique. Contient : photos, statistiques, moments importants, voyages, promesses réalisées, temps passé ensemble.

Export : PDF, impression, livre physique.

## 24. Widgets
